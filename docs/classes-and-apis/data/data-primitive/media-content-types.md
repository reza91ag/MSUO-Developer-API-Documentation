# Media & Content Types

`Data.media` is a nullable `Media` object from `MSUOTools.MediaTools`; `ContentType` resolves `media?.MediaType ?? "application/json"`. The full media API is outside the `Data` class and should be documented from its owning source before adding signatures.

**Source:** `Runtime/Component/DUP/Data.cs` (uploaded `src.zip`).
