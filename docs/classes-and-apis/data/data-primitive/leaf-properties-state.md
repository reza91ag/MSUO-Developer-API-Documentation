# Leaf Properties & State

Public fields/properties include `id`, `type`, `value`, `media`, `ContentType`, `IsAuthenticated`, `lastProcessorID`, `needsDependencies`, `watchDog`, and `children`. `ContentType` returns the media type when media exists, otherwise `application/json`. These are source declarations, not a guarantee that every property is serialized.

**Source:** `Runtime/Component/DUP/Data.cs` (uploaded `src.zip`).
