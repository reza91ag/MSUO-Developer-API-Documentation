# Acknowledgement Responses

`Data.Ack(string type, string value)` is a static factory used by the persistence logic nodes to return acknowledgement DUPs. It is not itself a persistence operation.

**Source:** `Runtime/Component/DUP/Data.cs` (uploaded `src.zip`).
