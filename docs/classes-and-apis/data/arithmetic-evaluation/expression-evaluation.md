# Expression Evaluation — Eval

`Data.Eval(string expression, IEnumerable<string>? filter = null, bool exclude = false)` returns a new DUP and does not mutate the original. The implementation uses NCalc.

**Source:** `Runtime/Component/DUP/Data.cs` (uploaded `src.zip`).
