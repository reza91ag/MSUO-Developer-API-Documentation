# Data-Naive CRUD

Pattern-driven CRUD on recursive DUP structures: `Read`, `Add`, and `Remove`. Unlike Table CRUD, these methods resolve structural patterns rather than only manipulating a keyed child dictionary.

**Source:** `Runtime/Component/DUP/Data.cs` (uploaded `src.zip`).
