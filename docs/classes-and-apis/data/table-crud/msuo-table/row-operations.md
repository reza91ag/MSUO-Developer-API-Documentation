# Row Operations

`ReplaceRow(string row, Data replacement, string? where = null)` resolves row by dictionary key then `Data.id` and replaces it if the optional condition matches. `ReplaceRow(Data replacement, string? where = null)` uses the replacement ID.

**Source:** `Runtime/Component/DUP/Data.cs` (uploaded `src.zip`).
