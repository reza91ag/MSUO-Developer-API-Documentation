# Expression Evaluation — Eval

`MsuoTable.Eval(expression, filter, exclude, where)` returns a new collective DUP containing cloned rows with evaluated value members where conditions match. The class also provides `EvalRow`, `EvalColumn`, and `EvalCell`. The expression evaluator is NCalc-based.

**Source:** `Runtime/Component/DUP/Data.cs` (uploaded `src.zip`).
