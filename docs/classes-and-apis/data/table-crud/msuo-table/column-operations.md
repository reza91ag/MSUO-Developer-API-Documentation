# Column Operations

`RemoveColumn(string column, string? where = null)` and `ReplaceColumn` overloads operate on value members of selected rows. `ReplaceColumn` accepts either an object value or evaluated `Data`.

**Source:** `Runtime/Component/DUP/Data.cs` (uploaded `src.zip`).
